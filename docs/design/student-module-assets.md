# Student module reference design

The supplied lesson screenshot defines the composition: back link, garden banner, live module title and description, dynamic syllable board and flashcard, purple progress bar, numbered illustrated reading cards, subdued locked previews, and a separate lavender assessment panel. The shared sidebar keeps Aralin selected on nested module routes. Small screens use a single readable column and reserve a separate banner illustration area; the decorative board is hidden on narrow phones to keep it away from the characters and copy.

## Source data and learning behavior

Module.tsx still reads /student/learn/module/:moduleId. Titles, descriptions, instructional types, exact target strings, item IDs, item order, completion records and assessment IDs are supplied by that authenticated response. No new course, word list or fixed five-item lesson is embedded in the application. All seventeen Beginner modules use this design: the first-letter module, the fifteen syllable families, and Pagbuo ng Salita. Existing additional phrase/paragraph curricula retain long-form reading, story warm-up and decoding checks.

Each item retains the prior rule: it is locked if its preceding item is incomplete. Showing a locked target and picture is preview only; its audio/practice controls are absent. The assessment button remains disabled until every delivered item is complete and the real assessment ID is used for navigation. Empty and failed responses never produce fake items or completion.

Speech recognition, assessSpeech, Filipino TTS, saved speed settings, recordVerifiedAnswer receipts, XP/badge responses, pronunciation feedback, retrying the same pending answer and query invalidation remain in use. A compact TTS control has a target-specific accessible label without changing its synthesis request. Recognition is stopped on navigation and callbacks/receipts from another module cannot replace the current module's feedback. Shared recording/saving state prevents overlapping practice attempts. Word meanings and slow speech remain available in expandable help; paragraph reading retains its prior presentation and full feedback.

Pictures use Filipino examples of the displayed sound. Ba uses bata, berde, bibe, bote and buko. Every one of the 75 syllables across the fifteen families now has an illustration: 71 have a matching example word and nge/wo/wu/yi have explicitly labeled sound-practice mascot pictures. The first-letter set is also illustrated. The relevant letters are highlighted in each example, including sounds within a word. Exact whole-word targets use their own picture where available. Unrecognized extra content retains a neutral fallback. Picture captions are examples; only content_text is sent for audio and answer verification. No backend, schema or curriculum data changes were made.
