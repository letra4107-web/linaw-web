# Teacher Lessons reference

The Teacher Lessons page follows the supplied reference: a warm pink/cream classroom banner, purple-blazer teacher illustration, yellow note and framed teaching message; a white creation form on the left; and a Lesson Library panel on the right. It reuses the shared Home sidebar without a Lessons-specific sidebar variant.

The header reuses the existing classroom and transparent Teacher assets. The library's transparent owl-reading illustration is `src/assets/teacher/lessons-reading-owl.png`, created with the imagegen skill. The owl, pink book, colorful book stacks, leaves and floating books form an illustration-only asset. Headings, counts, notes and lesson records remain editable HTML driven by actual data. Artwork recreates the reference's style and is not claimed to be pixel-identical to its original illustrations.

The create form retains the existing `lessons` table and `lesson-pdfs` storage flow: teacher ID, title, description, subject, grade, storage path/bucket, public/legacy URL, filename and published state. No database columns or backend routes are added. Title and description counters use 100 and 500 characters for new lessons. Subject and grade choices retain the existing values.

The description toolbar inserts a small text-formatting subset into the existing text field: bold, italic, underline, bullet/numbered lists, indentation, links and emoji. Formatted descriptions render safely as React text/elements in the detail preview, with no HTML interpretation. Old plain-text descriptions remain readable. HTTP/HTTPS links are supported; script/data URLs are not made into links. Formatting markers count toward the character limit. Editing an older longer record does not silently truncate it.

File selection and drag/drop share validation for nonempty PDF content and the advertised 50MB limit. A file-selection revision guard keeps an older asynchronous check from replacing a newer file or restoring a cleared file. Pending saves prevent conflicting form actions. Failed uploads or metadata saves preserve the draft.

The library queries the authenticated Teacher's own lessons. It has distinct loading, empty and failure states, real totals, search and bounded pagination for populated libraries. Existing file preview, publish/draft and delete actions remain available. Metadata editing now uses the existing update capability. Delete requires confirmation. Updates/deletes explicitly filter Teacher ID as well as lesson ID, in addition to existing RLS. The native detail/edit/confirmation dialogs support keyboard focus and Escape, with pending-action guards.

The separate PDF-material/assignment workspace and “Mga PDF” shortcut have been removed. Legacy `/teacher/lessons?tab=pdf` links redirect to `/teacher/lessons`, removing the obsolete tab parameter while preserving unrelated query parameters. Teacher navigation now opens the remaining lesson form/library or the student roster for existing assignment records. The normal lesson PDF upload stays available; historical material and assignment records are preserved. Home counts published lessons owned by the current teacher and refreshes after lesson changes. Desktop uses two panels; smaller viewports stack the panels and fields. Dark mode retains the structure with muted surfaces. The existing Comic Sans and accessibility preferences remain in effect.
