# LinawLetra email templates

## Supabase Auth templates

Copy the HTML body into the matching template in Supabase Dashboard under **Authentication → Email Templates**.

- **Confirm signup**: `supabase-confirm-signup.html`; subject: `Kumpirmahin ang iyong email sa LinawLetra`
- **Reset password**: `supabase-reset-password.html`; subject: `I-reset ang password mo sa LinawLetra`

Both templates use Supabase's `{{ .Token }}` OTP because the app asks the user to enter a code.

## Student credentials

The student enrollment email is generated by the server using `childEnrollmentEmail` in `server/lib/emailTemplates.js`. It includes the username, temporary password, grade/reading level, and login steps. No Supabase Auth template needs to be pasted for this message.
