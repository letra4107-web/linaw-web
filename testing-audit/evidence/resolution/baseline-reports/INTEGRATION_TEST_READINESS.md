# Integration test readiness

Audit date: **2026-10-21, Asia/Manila**. Working-tree source, including pre-existing edits, was audited. No shared Supabase requests, schema changes, record changes, account creation, email delivery, commit, push, or deployment were performed. PASS applies only to the named executed assertion. Source indexing, compilation, mocks, and anonymous redirects do not establish complete signed-in functionality.

## Verified local boundaries

Real local HTTP tests instantiate the production Express app using a loopback-discard Supabase URL and synthetic key. They cover health, security/CORS/version/request headers, malformed/oversized JSON, unknown paths and anonymous rejection for every discovered protected endpoint. They never execute successful database CRUD. Other integration tests run actual routers with mocked persistence/Auth/Storage boundaries, including cross-parent material ownership, drill input/history protection, Admin settings and atomic-assignment RPC error mapping. Nodemailer stream composition and Multer multipart upload are exercised locally without SMTP. TTS tests mock synthesis, dictionaries, fallback and rate limits.

The expanded [../server/tests/auditRoleMatrix.test.js](../server/tests/auditRoleMatrix.test.js) invokes actual Express routers in process, with real role middleware and a fake profile store. All 235 combinations pass. Its first HTTP transport run had 71 fetch failures; that evidence is retained as role-matrix-http-original.tap. The transport was changed explicitly to avoid the environment's loopback dependency. An in-process pass does not clear the HTTP transport failures.

## Database boundary

The disposable PostgreSQL runner never loads application env files and uses random synthetic local credentials. The first run failed during initdb restricted-token setup. An approved outside-sandbox retry failed with listen EACCES on 127.0.0.1. Both evidence files and verifier FAIL outcomes remain recorded; the planned SQL assertions were not executed in this audit. They are BLOCKED, not regression passes inferred from older reports.
